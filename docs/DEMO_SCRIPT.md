# Demo Video Script

Hi, we’re Team Devtwin, and this is Borewell Ledger, a community groundwater early-warning system. In many Indian societies and farms, the borewell is the main water source, but owners only find out the water level is falling when it runs dry, and each owner sees only their own well, so nobody knows whether the problem is local or the whole area is declining. With Borewell Ledger, people log the depth to water in their borewell from a phone, and we compare each well’s rate of decline with the wells around it. Here’s the live app. The dashboard shows the wells that need attention first, and the map shows every well by status: green for normal, amber for watch, and red for critical. Let’s add a reading: I pick my well, enter the depth, and submit, and the status updates immediately. On the well page, this chart shows depth over time, and this well is falling 0.9 meters a month while its neighbors are falling only 0.2, so four times faster. Now I’ll run the analysis, and it finds a critical alert and an area-wide alert for this locality, where several wells are falling together. The AI analysis explains in plain language what is happening, lists possible reasons, says how confident it is, and suggests ways to save water, and I can also ask the assistant questions like “Which of my wells is most at risk?” and it answers using this well’s own data. Everything runs on AWS and is deployed with AWS SAM, which is open source: the frontend is hosted on AWS Amplify, API Gateway calls Lambda functions, data lives in DynamoDB, EventBridge runs the analysis on a schedule, SNS sends alerts, and Amazon Bedrock powers the AI analysis and chat, so it’s fully serverless and costs almost nothing when idle. The wells in this demo are simulated data, and real readings plug straight in, and next we plan to add sensors and WhatsApp logging. Thanks for watching.
