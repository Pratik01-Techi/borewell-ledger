# Borewell Ledger – Project Write‑up

## Overview

Borewell Ledger is a community‑driven groundwater early‑warning platform built for India. It aggregates depth‑to‑water readings from borewells, visualises them on a shared map, and uses deterministic analysis together with generative AI (Amazon Bedrock Nova Micro) to surface declining wells, generate alerts, and suggest water‑saving actions.

## Why it matters

Groundwater supplies ≈ 60 % of India's drinking water, yet most borewell owners have no visibility into the health of their wells or the surrounding aquifer. By consolidating data across societies, farmers, NGOs and water officers, the platform enables early detection of over‑extraction and coordinated conservation.

## Key Features

- **Community map** – All wells displayed on a unified MapLibre map with status colouring and filters.
- **Peer comparison** – Each well’s decline rate is benchmarked against nearby wells (3 km radius).
- **Deterministic alerts** – Transparent, unit‑tested rules flag WATCH and CRITICAL wells and area‑wide hotspots.
- **AI analysis & plans** – Nova Micro provides natural‑language insights, water‑saving plans and an interactive chat.
- **Multilingual UI** – English, हिन्दी and ગુજરાતી.
- **Exportable data** – CSV of wells, PDF of AI‑generated plans.

## Technical Highlights

- **Frontend**: React 18 + Vite + TypeScript + Tailwind CSS.
- **Backend**: Python 3.12 Lambda functions (ARM64) on AWS SAM, DynamoDB (on‑demand), API Gateway (HTTP), SNS email alerts, EventBridge daily analyzer.
- **AI layer**: Amazon Bedrock Nova Micro with deterministic fall‑backs.
- **Infrastructure as code**: `template.yaml` defines all AWS resources.
- **Cost‑guard**: AWS Budgets limits spend to <$5 / month.
